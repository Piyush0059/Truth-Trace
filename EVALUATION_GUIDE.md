# TruthTrace Evaluation Guide

## Running the in-app demonstration

1. Navigate to the **Lab** tab in TruthTrace.
2. The current demonstration suite contains **8 test queries**, grouped to exercise different situations:
   - Answerable: potentially relevant evidence is present in the sample text.
   - Unanswerable: the sample text lacks the needed evidence.
   - Conflicting: sources disagree.
   - Paraphrased: the question uses wording different from the source.
3. Select **Run Benchmark Experiment**.
4. The app compares these conditions:
   - Baseline (no retrieved context)
   - Lightweight word/character-trigram vector retrieval
   - BM25 keyword retrieval
   - Hybrid ranking using Reciprocal Rank Fusion (RRF)
5. Inspect the displayed outputs and use **Export JSON** to review the values generated by this prototype.

## How to interpret the displayed values

The benchmark is a small demonstration set for development and inspection, not a peer-reviewed benchmark. It is not sufficient to establish general performance claims.

In particular, some claim-faithfulness and citation-support values use preset formulas rather than independently human-labelled ground truth. Treat them as illustrative indicators, not as a measured hallucination rate or proof of citation correctness. Retrieval metrics also depend on how the demonstration queries and relevant passages are defined.

## Recommended manual review

For each test query, record the relevant source passages before reviewing the system answer. Then check whether each factual claim is directly supported, contradicted, unsupported, or ambiguous. Keep human-labelled judgments separate from the app's automatically produced labels and scores. A rigorous future evaluation should document the corpus, query set, annotation criteria, model configuration, repeated runs where needed, and disagreements between reviewers.

The current app is a prototype intended to make these evaluation issues visible. Results should not be described as independently validated or publication-ready.
